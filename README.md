# Personal Networking Notes

This repository contains my personal notes, configurations, troubleshooting references, and lab exercises related to computer networking and Cisco technologies.

The purpose of this repository is to document concepts in a practical and easy-to-review format while progressing through the Cisco certification path:

- CCNA 200-301
- CCNP ENCOR 350-401
- CCNP ENARSI 300-410

---

## Topics Covered: 
- Network Fundamentals
- IPv4 and IPv6 Addressing
- Subnetting
- ARP and ICMP
- VLANs and 802.1Q Trunking
- Spanning Tree Protocol
- EtherChannel
- Static and Dynamic Routing
- OSPF
- First Hop Redundancy Protocols
- HSRP
- VRRP
- Access Control Lists
- NAT and PAT
- DHCP
- Network Services
- Cisco IOS / IOS-XE Configuration
- Routing and Switching Troubleshooting
- Network Automation and Programmability

---


## Repository Goal
The goal is not only to document commands, but to understand why the network behaves the way it does.
